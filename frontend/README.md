# Frontend IntelliFit

React, TypeScript, React Router e Vite. A configuração completa está no [README principal](../README.md).

```bash
npm ci
npm run dev
```

O backend deve estar ativo em `http://localhost:3000`. Para verificar tipos e gerar a versão de produção:

```bash
npm run build
```

O chat usa `src/services/chatService.ts`; regras de estoque e confirmações são executadas no backend.
